
To know how to use any linux command use man <name of linux command>

scp is used to copy files between local and remote computers 

copying from local computer to remote (Argon)- secure file copy (scp)
scp -p 40 <local file name> username@argon.hpc.uiowa.edu:<path/to/folder>  

copying from a remote computer to local computer 
scp -p 40 <username@argon.hpc.uiowa.edu>:/home/username/myfile.txt . (period here means copy to current dir)- (~ for home)
scp -r copy and entire dir 

Screen - used to keep shell running in the background. if you are downloading large files or running a job that requires long hours you can run that job in the screen 
restore using ->  screen -r

ls -list files in current dir 
options : -a (all)-h(human), -l(long formate) etc   

using the pipe (|) command 
linux command | grep parameter | parameter 
example 
la -la | grep tutor | wc
